# Budget Planner App

## Overview

This repository contains the budget planner project workspace. The current implementation includes a single React frontend container.

## Documentation

Project documentation is maintained in the CodeWiki:

- [CodeWiki Home](../kavia-docs/CodeWiki/index.md)

## Containers

- `react_frontend`: React (Create React App) frontend located at `budget-planner-app-251073-251087/react_frontend`.

## Current implementation note

The repository currently implements a minimal UI with a light/dark theme toggle. The broader budget planner feature set (transactions, categories, monthly summaries, charts, localStorage persistence, CSV export) is captured as a forward-looking specification in the CodeWiki and is not yet implemented in source code.
